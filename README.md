# かずちゃんの冷蔵庫

無料で動く、日本語の冷蔵庫在庫管理 Web アプリです。アカウント登録・API キー・依存パッケージのインストールは不要です。

## Mac で試す

1. このリポジトリのファイルを Mac にダウンロードして展開します。
2. 「ターミナル」を開き、`cd `（最後に半角スペース）を入力して、展開したフォルダーをターミナルにドラッグします。Enter を押します。
3. `python3 --version` を実行します。Python がなければ https://www.python.org/downloads/macos/ から Python 3 をインストールします。
4. `python3 -m http.server 8000 --bind 127.0.0.1` を実行します。
5. Safari で `http://localhost:8000` を開きます。
6. 食材を登録し、ページを閉じて再度開いても食材が残ることを確認します。
7. サーバーを止めるときは、ターミナルで Control + C を押します。

`index.html` を直接ダブルクリックする方法ではなく、上のサーバーから開いてください。同じブラウザー・同じアドレス・同じポートを使う必要があります。

## できること

- 食材名・数量・自由入力の単位を登録、編集、削除
- 冷蔵・冷凍・常温の分類、検索
- 賞味期限または消費期限を登録、期限の近い順に表示
- 使った数量を減らす（0になると「使う」ボタンが無効になります）
- 端末のブラウザー内に自動保存
- JSON ファイルへのバックアップと復元（復元は現在の在庫を置き換えます）

日付は任意です。数量に小数を使えます。期限の表示は食品の安全性を判定するものではありません。初期のサンプル食材は入れていません。

## iPhone とホーム画面

Mac の `localhost` は iPhone から開けません。iPhone で継続的に使うには、HTTPS の静的ホスティング（例：GitHub Pages）に、このフォルダーの公開用ファイルを置く必要があります。公開はこの作業では実施していません。

HTTPS で公開したページを iPhone の Safari で開き、「共有」→「ホーム画面に追加」を選びます。初回にオンラインで開き、オフライン用ファイルの保存が完了すると、電波がなくても利用できます。ホーム画面のアイコンと Web アプリ設定を同梱しています。実機の Safari での動作は公開後に確認してください。

## 保存について

在庫は localStorage に保存します。サーバーへ送信しません。Mac・iPhone・別のブラウザー間の自動共有はありません。Safari の通常画面とホーム画面のアプリでは保存領域の扱いが異なる場合があります。使用する画面を決めてから登録してください。ブラウザーのデータ消去や端末の変更で消えることがあるため、バックアップファイルを定期的に保存してください。プライベートブラウズは避けてください。

## ファイルと今後の拡張

- `index.html`：日本語画面
- `styles.css`：iPhone 向けの大きめの操作部品と淡いグリーンのデザイン
- `app.js`：在庫の操作とバージョン付きデータ保存
- `manifest.webmanifest`、`icon*`：ホーム画面用設定とアイコン
- `sw.js`：静的ファイルのオフラインキャッシュ

食材には固有 ID を付け、保存処理と表示処理を分けています。将来の写真は容量の大きな画像を localStorage に直接入れず IndexedDB 等へ保存し、食材 ID と関連付ける設計にできます。献立・買い物リストも食材 ID と連携できます。AI API を利用する場合は、秘密の API キーをブラウザー側の JavaScript に書かず、別のサーバー側処理が必要です。

アプリの静的ファイルを更新するときは、必要に応じて `sw.js` のキャッシュ名も更新してください。

## 第2段階：献立と買い物リスト

「献立を提案してもらう」を押すと、6つの無料レシピから在庫に合う料理を提案します。AIサービス・通信・料金は不要です。期限の近い食材を使う料理を優先し、期限切れや残り0は候補の在庫から除きます。提案は登録済みの食材名・別名との照合であり、すべての食材名に対応するものではありません。

分量は2人分の目安です。同じ単位なら不足量を計算します。単位が違う場合は「在庫あり・分量を確認」と表示し、勝手に重さや個数を換算しません。「作り方を見る」で手順を開けます。調理しても在庫を自動で減らさないため、実際に使った分を「使う」で減らしてください。

「足りない食材を買い物リストへ」で、買い足すものを保存します。同じ食材はまとめ、各料理で必要な量を並べます。複数の献立の分量を合計する機能はありません。購入済みのチェックと削除ができます。購入済みチェックでは在庫へ追加しません。買い物リストもブラウザーに残りますが、現在のバックアップ保存・復元は在庫のみを対象とし、買い物リストは含めません。

追加ファイル：`recipes.js` はレシピ集、`menus.js` は献立照合と買い物リストを担当します。将来のAI提案と切り分けて拡張できます。

### Mac のアプリを新しい版に更新する

同じGitHubブランチから新しいZIPをダウンロードします。更新前に、アプリの「バックアップ保存」を押してください。現在のターミナルで Control + C を押して停止し、新しく展開したフォルダーへ移動して、同じポート8000で起動します。Chromeも同じ `http://localhost:8000` を使えば在庫が引き継がれます。オンライン状態で再読み込みしてください。古い画面が残る場合は一度タブを閉じて開き直します。保存データを消す操作は不要です。
